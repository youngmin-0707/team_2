# 브라우저 기반 영상 장면 요약·음성 안내 계획

## 목표

Streamlit에서 MP4 파일 또는 웹캠 영상으로부터 브라우저가 JPG 프레임을 추출한다. 최대 60초 영상의 최대 12개 프레임만 FastAPI로 보내 OpenAI Vision으로 장면을 통합 요약하고, OpenAI TTS로 한국어 또는 영어 MP3 안내 음성을 즉시 재생한다.

## 구현 순서

1. 영상 프레임 분석 결과 스키마와 입력 검증을 추가한다.
2. OpenAI Vision을 사용해 여러 프레임을 통합 요약하는 서비스와 `/api/media/video-analysis` API를 구현한다.
3. Streamlit에서 직접 호출할 수 있도록 CORS를 구성한다.
4. 브라우저 Canvas/MediaRecorder 기반 Streamlit 화면을 추가한다. 원본 동영상은 서버에 업로드하지 않고 프레임만 전송한다.
5. 분석 성공 직후 기존 `/api/media/tts`로 MP3를 생성·재생한다.
6. API 검증·성공·오류 경로를 테스트한다.

## 결정 사항

- 입력: MP4 파일 업로드 및 웹캠 촬영
- 분석: 자유 장면 요약, OpenAI Vision 고정
- 프레임: 60초 이하, 약 5초 간격, 최대 12장
- 결과: 한국어/영어 선택, 통합 요약과 MP3 한 개만 제공
- 보관: 요청 처리 중 메모리에서만 사용하고 원본·프레임을 저장하지 않음
